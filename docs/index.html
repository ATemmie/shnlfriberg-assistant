/ how it works

一轮游戏实录

脚本自动读取页面反馈，引擎计算推荐，全自动闭环。

STEP 01 脚本读取反馈
你输入选手名猜完后，脚本自动扫描页面表格的 CSS 类名（.correct / .close / .wrong）， 提取 7 个属性的级别和方向提示，发送到本地服务器。
STEP 02 引擎过滤 + 推荐
服务器收到反馈后，过滤引擎根据规则缩小候选池， 推荐算法用信息熵算出最优下一猜，返回 JSON 结果。
645 → 候选池逐步缩小
STEP 03 自动填入推荐
推荐名自动填入搜索框（可配置是否自动提交）。 重复直到猜中。全程 不需要离开游戏页面。
自动模式 ✅
反馈颜色映射：
correct · 精确匹配
close · 相近
wrong · 不匹配

/ features

功能亮点

浏览器脚本 + 本地引擎的组合优势。

🎯

自动读取反馈

脚本通过 CSS 类名检测（.correct / .close / .wrong）自动提取每格反馈级别，支持箭头提示（↑ higher / ↓ lower）解析。

🤖

自动填入 + 提交

推荐结果自动填入搜索框。可配置 autoSubmit=true 自动提交，也可手动确认。支持混淆模式增加挑战性。

📊

信息熵推荐

对每个候选模拟对全部选手的猜测结果，按反馈模式分组，选择信息增益最大的选手推荐。优先推荐能最大化缩小候选池的选手。

🖥️

本地运行

Python Flask 服务器运行在本地，数据不出本机。支持 /api/reset、/api/status、/api/guess 三个端点。

/ usage

安装使用教程

跟着以下 4 步，从零开始配置。

1

安装 Tampermonkey（浏览器扩展）

根据你使用的浏览器，点击对应的链接安装 Tampermonkey 扩展：

🌐 Chrome 安装 🔷 Edge 安装 🦊 Firefox 安装
✅ 确认安装成功： 浏览器右上角应该出现一个 🧩 拼图或 🐵 猴子图标。 点击它就能看到 Tampermonkey 的菜单。
2

安装用户脚本

解压下载的 ZIP 包，找到 shnlfriberg-helper-v2.user.js

方法一（推荐）： 直接将 .user.js 文件拖入浏览器窗口。 Tampermonkey 会自动检测并弹出安装页面，点击「安装」即可。

方法二（手动）： ① 点击浏览器右上角 🐵 Tampermonkey 图标 → ② 选择「添加新脚本」→ ③ 用记事本打开 .user.js 文件，全选复制内容 → ④ 粘贴到 Tampermonkey 编辑器中 → ⑤ 按 Ctrl+S 保存。

⚠️ 如果没反应： 确保文件后缀是 .user.js 而不是 .txt。 如果 Windows 隐藏了后缀名，在文件资源管理器中勾选「查看 → 文件扩展名」。
3

启动本地服务器

方法一（推荐）： 双击 一键启动.bat。 它会自动检查 Python、安装依赖、在后台启动服务器、并帮你打开脚本安装页面和游戏网址。

方法二（手动）： 双击 start_server.bat， 或打开终端按下面操作：

终端
# 进入项目目录
$ cd 解压后的文件夹路径
 
# 安装依赖（首次运行需要）
$ pip install -r requirements.txt
 
# 启动服务器
$ python server.py
* Running on http://127.0.0.1:5000
✅ 确认服务器运行成功： 终端显示 Running on http://127.0.0.1:5000 就说明启动好了。 ⚠️ 不要关这个终端窗口，关掉服务器就停了。
4

开始游戏

打开 shnlfriberg.online， 点击「单人游戏」开始一局。

✅ 如果一切正常，页面右下角会出现一个浮动面板：

🔍 推荐 645 候选
refrezh
自动填入 提交 重置

操作步骤：

① 看面板推荐的名字 → ② 在游戏输入框输入该名字 → ③ 提交猜测 → ④ 页面表格出现反馈颜色 → ⑤ 脚本自动读取并发送到服务器 → ⑥ 面板更新推荐 → 重复直到猜中 🎯

⚙️ 可配置选项（在脚本第 30~36 行）：
_shnl_autoFill = true — 自动把推荐名填入搜索框
_shnl_autoSubmit = true — 自动点击提交按钮
_shnl_confuse = false — 设为 true 开启混淆模式（随机给错误反馈，增加难度）
_shnl_responseDelay = 1500 — 提交后等待时间（毫秒），网慢可以调大
