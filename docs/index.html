/ 安装指南

扩展版 4 步搞定

无需 Tampermonkey、Python、终端。解压即用。

1

下载并解压

下载 shnlfriberg-helper-v3.1-chrome-extension.zip，解压到任意文件夹。

2

打开扩展管理页

Edge 打开 edge://extensions/ ， Chrome 打开 chrome://extensions/

3

加载扩展

打开右上角「开发人员模式」→ 点击「加载解压缩的扩展」→ 选择解压后的文件夹。

4

开玩

去 shnlfriberg.online 开始游戏，右下角会出现助手面板。

/ FAQ

常见问题

扩展版和用户脚本版有什么区别？

扩展版是 Chrome/Edge 扩展，解压拖入浏览器即可用，零依赖。用户脚本版需要装 Tampermonkey 同时后台跑 Python 服务器。两者推荐逻辑相同，扩展版更稳定易用。

安装后没看到面板？

确认扩展管理页已启用扩展，然后刷新 shnlfriberg.online 页面。面板出现在页面右下角。

会检测游戏重开吗？

会。扩展通过三种方式检测：表格行数归零、界面出现"再来一把"按钮、多人模式检测"第 X 局"文本变化。检测到后自动重置候选人池。

我怎么确定哪个推荐最好？

面板显示 Top 5 推荐，按信息熵值降序排列（E 值越高越好）。第一个（带金色左边框）是算法认为最优的猜测。

数据更新频率？

选手数据随扩展版本更新。目前收录 645 名职业选手，覆盖主要赛区和队伍。

猜中后不显示正确答案？

猜中后面板会显示答案卡片（含选手名和战队），点击可填入输入框。
